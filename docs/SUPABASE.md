# Подключение Supabase (база данных в интернете)

Без настройки игра хранит данные в папке `data/` (файлы). Supabase нужен, если сервер запускается на хостинге,
где файлы пропадают при перезапуске, или если хочется смотреть и редактировать данные в таблицах.
Хранятся: аккаунты (ник, хеш пароля, деньги, ресурсы, кирки, чары) и изменения карты.

## Шаги
1. Зайдите на supabase.com, создайте аккаунт и **New project** (запомните пароль базы, в игре он не нужен).
2. Откройте **SQL Editor → New query**, вставьте содержимое файла `server/storage/supabase.sql` и нажмите **Run**.
   Появятся таблицы `accounts` и `world` (доступ к ним закрыт для публики).
3. Откройте **Project Settings → API** (в новых версиях панели может называться «API Keys») и скопируйте:
   - **Project URL** (вида `https://xxxx.supabase.co`) → `SUPABASE_URL`
   - ключ **service_role** (секретный) → `SUPABASE_SERVICE_KEY`
4. Задайте переменные и запустите сервер:
   - Файл `.env` (скопируйте `.env.example`) и `npm run start:env` (нужен Node 20.6+), или
   - Windows PowerShell: `$env:SUPABASE_URL="https://..."; $env:SUPABASE_SERVICE_KEY="..."; npm start`
   - Linux/macOS: `SUPABASE_URL=https://... SUPABASE_SERVICE_KEY=... npm start`
   - Хостинг (Render, Railway и т. п.): добавьте эти две переменные в настройках сервиса.
5. В консоли сервера должно появиться `Сохранения: Supabase (xxxx.supabase.co)`.

## Важно
- Ключ **service_role** даёт полный доступ к базе. Держите его только на сервере: не вставляйте в клиентский код (`client/`),
  не выкладывайте `.env` на GitHub. Если ключ утёк — пересоздайте его в настройках Supabase.
- Если база недоступна при запуске, сервер **не стартует** (чтобы пустое состояние не затёрло данные). Если база пропала
  во время игры, записи повторяются каждые 30 секунд и при остановке; сообщения об ошибках видны в консоли.
- Карта хранится одной записью (весь список изменений). Для мира такого размера это единицы мегабайт; если мир сильно
  вырастет, карту стоит разбить на части по чанкам (меняется только `server/storage/supabase-store.js` и `persistence.js`).
- Бесплатные проекты Supabase могут приостанавливаться при долгом отсутствии активности. Актуальные условия смотрите на сайте.
- Перенос из файлов: аккаунты из `data/accounts.json` не переносятся автоматически. Игрокам проще зарегистрироваться заново,
  либо попросите нейросеть написать разовый скрипт импорта (дайте ей `docs/AI_GUIDE.md` и `server/storage/supabase-store.js`).
- Другая база (PostgreSQL напрямую, SQLite, MongoDB): создайте файл `server/storage/имя-store.js` с теми же четырьмя методами
  (`loadAccounts`, `saveAccounts`, `loadWorld`, `saveWorld`) и подключите в `server/storage/index.js`.
